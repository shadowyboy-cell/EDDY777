# اسم الميزانية — اسم الميزانية V1.0

نسخة Android شخصية قابلة للبناء من تطبيق إدارة مالية محلي.

## الوظائف

- واجهة عربية RTL.
- رصيد حالي قابل للتعديل.
- دخل ومصروفات.
- SQLite محلي.
- قراءة SMS الواردة عند الضغط على «مزامنة الرسائل البنكية».
- استخراج المبلغ من الرسائل العربية والإنجليزية الشائعة.
- اكتشاف دخل/مصروف.
- تصنيف أولي للمتاجر والخدمات.
- منع تكرار رسالة SMS بعد مزامنتها.
- تنبيه عند انخفاض الرصيد عن الحد المحدد.
- تحليل المصروف حسب الفئة.
- قائمة احتياجات محلية.
- لا يتم حفظ نص SMS الخام في قاعدة البيانات.

## متطلبات البناء

- Flutter SDK حديث (يفضل Flutter 3.47 stable أو أحدث متوافق).
- Android Studio + Android SDK.
- JDK 17.
- جهاز Android 7.0/API 24 أو أحدث.

Flutter 3.47 يدعم Android API 24 وما فوق ضمن المنصات المدعومة، وتوصي وثائق Flutter باستخدام `flutter build apk` لإنشاء APK release. 

## البناء

من داخل مجلد المشروع:

```bash
flutter pub get
flutter build apk --release
```

سيظهر APK عادة في:

```text
build/app/outputs/flutter-apk/app-release.apk
```

ويمكن تثبيته على الهاتف مباشرة، أو استخدام:

```bash
flutter install
```

## أول تشغيل

1. ثبّت التطبيق.
2. افتح اسم الميزانية.
3. من الإعدادات أدخل رصيدك الحالي وحد التنبيه.
4. اضغط «مزامنة الرسائل البنكية».
5. وافق على READ_SMS.
6. راجع العمليات المستخرجة قبل الاعتماد عليها.

## صلاحية SMS

هذا التطبيق مخصص لهاتفك الشخصي، لذلك يستخدم `READ_SMS` فقط عند طلب المزامنة. حزمة `flutter_sms_inbox` توضح رسميًا أنها Android-only وتتطلب `READ_SMS` وطلب الصلاحية وقت التشغيل.

هذه النسخة لا تستخدم مراقبة SMS دائمة في الخلفية. هذا مقصود لتقليل الصلاحيات واستهلاك البطارية. يمكن إضافة BroadcastReceiver في V2.

## ملاحظات مهمة

- استخراج الرسائل البنكية يعتمد على صياغة الرسالة. البنوك وشركات البطاقات قد تستخدم قوالب مختلفة؛ لذلك قد تحتاج قواعد إضافية.
- الرصيد الحالي هو قيمة مرجعية تدخلها أنت، وليس اتصالًا مباشرًا بالحساب البنكي.
- لا تعتمد على التطبيق كمصدر محاسبي نهائي قبل مراجعة العمليات المستخرجة.
- مقارنة أسعار D4D/ClickFlare والمتاجر لم تُفعل بعد؛ تحتاج طبقة بحث/تكامل مستقلة في V2.

## خصوصية

المشروع مصمم ليبقي البيانات المالية محليًا. لا توجد خدمة سحابية أو API خارجي في V1.

## SMS التلقائي في V1.1

- `SmsReceiver.kt` يستقبل `SMS_RECEIVED` على Android.
- يتم تحليل الرسالة محليًا إلى مبلغ/نوع/متجر/تصنيف/وقت/معرف.
- لا يتم تخزين نص SMS الخام.
- إذا كان التطبيق مغلقًا، تحفظ العملية المستخرجة محليًا في `pending_sms` وتتم إضافتها إلى SQLite عند تشغيل التطبيق.
- إذا كان التطبيق مفتوحًا أو عاد للعمل، تتم معالجة العمليات المعلقة تلقائيًا.
- لا يتم إرسال الرسائل إلى الإنترنت.
